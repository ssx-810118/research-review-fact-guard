# 引用与来源标注规范（citation-spec）

> 本规范定义 Skill 生成科研综述时正文写作与来源标注的全部规则，与 `scripts/common.py`（标注解析与事实/分析句判定）、`scripts/audit_review.py`（审计检查）的实现保持一致。属通用规范，不依赖任何特定材料内容。

## 1. 标注格式

- 标注写在**事实句句末**，格式为：`【来源材料名称，具体位置】`（全角方头括号，中文逗号分隔）。
- **材料名称**：优先使用材料包中的文档全名（如《行业白皮书节选》《论文摘要集》等）。审计阶段支持类别短名归一（白皮书／论文摘要·论文集／新闻／访谈／评论／评测·评测报告／调研数据·数据表），但短名在多文档场景下存在歧义风险，正式行文一律用全名。
- **位置**：必须能唯一定位到文档内的章节、编号条目、表格或数据行（见第 2 节）。
- 方括号 `[材料名，位置]` 亦可被解析，但输出终稿统一使用全角方头括号。

## 2. 位置（locator）写法规范

| 材料组织方式 | 推荐写法 | 示例 |
|---|---|---|
| 章节化文档（白皮书类） | 章号或章节标题原文 | `第一章`、`第三章 资本市场与投资趋势` |
| 编号小节文档（评测报告类） | 小节标题原文（编号+标题） | `1.3 评测结论`、`6.1 推理优化技术` |
| 编号条目集（新闻/评论/访谈/论文摘要） | 条目编号 | `新闻三`、`评论十二`、`访谈一`、`论文A` |
| 文档内表格 | 表号（或原文页码+表号） | `表2`、`第1页·表1` |
| 电子表格 | 行级定位；汇总统计用"汇总" | `第21行`、`汇总` |
| 附录/说明性章节 | 标题原文 | `附录` |

- 定位缺失时审计将标记 `LOCATOR_NOT_FOUND`；定位粒度以"数值能在被引位置复现"为准，宁细勿粗。

## 3. 事实句与分析句

- **事实性陈述**（数据、事件、方法、结论、谁在何时说了什么）**必须标注来源**。
- **分析性归纳**（总结、评价、趋势判断、原因推断）不要求逐条标注，典型引导语包括：综上／总体来看／本报告认为／本报告判断／表明／说明／可见／建议／展望等。
- 分析句**不得夹带未经标注的新事实**：一旦出现数字、专名事件或"谁说了什么"，该句按事实句处理，须补充来源。
- 含数字的句子一律按事实句审计，无论措辞是否偏分析。

## 4. 数值—来源绑定

- 句中每个数值都必须能在**被引位置**复现（容差 3%，处理四舍五入与单位换算）。
- **禁止张冠李戴**：不得把 A 文档的数字标注到 B 文档（审计会比对数值池判定 `MISATTRIBUTED`）。
- 派生值（比值、差值等）引用时须可在被引位置由原始数字复算（容差 4%）；无法复算的派生数字不得写入事实句。
- 修饰词与区间随原文保留（约／超／近／接近／X 到 Y），不做二次加工；单位按原文口径书写，不混用换算后数值。
- 表头单位与数值分离的表格（如"研发投入（万元）"列名），转述时保持"数值与单位分列"的写法，避免把列名单位误并入数值。

## 5. 表格与图表引用

- 表题行标明编号与主题（如"表X-Y 主题"），紧随其后为表格本体。
- 表格**末行或列内标注来源**（如"数据来源：【材料名，表N】"），表格数据须与材料一致，不引入表外数字。
- 表格是对分歧主题做"多方数据并列"的推荐载体：各方口径分列，来源逐列标注。

## 6. 传闻与诱导性表述

- 传闻线索词：据报道／据悉／有消息称／据称／秘密提交／传闻／或超／有望成为／被指等。**此类表述不得写成确定事实**。
- 处理方式：加限定语转述（如"据报道……尚未经证实"），或显式标注其证据层级（见 `audit-rubric.md`）。
- 厂商自报参数、访谈与评论中的判断属低证据层级来源：引用时注明"自报口径／观点"，**不与一手实测混写为同等事实**；与独立实测差异显著的自报高值不得当作事实。

## 7. 分歧主题

- 引用存在多源分歧的主题（同一指标多来源数值不一致、结论相反）时，所在段落**必须包含分歧分析**：各方数据并列 → 口径与条件差异拆解 → 综合判断。
- 禁止悄然选边；跨层级冲突按证据层级裁决（见 `audit-rubric.md`），同层级冲突并陈处理。
- 分歧各方的数据均须逐条标注来源，判断部分以分析句呈现。

## 8. 禁止事项

- 不引入材料外知识；不使用网络检索结果替代材料来源。
- 不硬编码特定材料内容；本规范全部规则为通用规则。
- **未通过审计的数字与结论不得进入终稿**（修订闭环见 `audit-rubric.md` 第 5 节）。
