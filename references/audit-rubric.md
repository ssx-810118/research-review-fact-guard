# 证据强度分层与审计评级标准（audit-rubric）

> 本标准定义自审机制的证据评级、冲突裁决规则与忠实度审计口径，与 `scripts/audit_review.py`（独立审计）与 `scripts/numeric_audit.py`（程序化数值校验）的实现保持一致。属通用标准，不依赖任何特定材料内容。

## 1. 证据强度分层（L1–L5）

| 层级 | 定义 | 典型来源 | 引用规则 |
|---|---|---|---|
| **L1 一手可核验** | 可直接回查原始出处且经独立程序核验 | 同行评审论文正文结论；官方统计口径；统一条件实测原始表格 | 可作为事实主引用；冲突时的裁决基准 |
| **L2 权威机构转述** | 权威机构发布的行业报告与预测 | 行业白皮书；权威咨询机构的市场规模测算与预测 | 可作为事实引用，须注明机构口径与统计边界 |
| **L3 媒体报道** | 新闻媒体对事件与数据的报道（含转引） | 行业新闻集中的报道条目 | 引用时注明"报道口径"；转引数据标注转引链路 |
| **L4 个人观点与自报参数** | 从业者访谈、评论、企业自报数据 | 专家访谈；行业评论；调研数据表中的企业关键参数 | 必须注明观点主体／自报口径；不得与一手实测混写为同等事实；与独立实测差异显著的自报高值不得当作事实 |
| **L5 传闻** | 未经证实的传闻、指控、未公开信息 | 含"据报道／秘密提交／据称／或超／有望成为"等线索词的表述 | **不得作为定论**；仅以限定语转述并标注信息层级，不参与冲突裁决 |

- 分层依据为**信息链路到原始出手的距离**：每多一层转述，数值失真与诱导风险递增。
- 证据强度分层用于写作期的引用取舍与审计期的冲突裁决，是"负样本校准"的依据：L3–L5 内容视为潜在负样本，须与 L1–L2 对照后才可采信。

## 2. 层级冲突裁决规则

1. **跨层级冲突**：以高层级证据为准；低层级信息不删除，作为"口径／条件／立场差异"显式呈现，并解释差异成因（统计边界、实验条件、立场偏差等）。
2. **同层级冲突**：并陈各方数据（推荐多方数值表）→ 口径与条件差异拆解 → 给出综合判断；**不得悄然选边**。
3. **L5 与任何层级冲突**：L5 不参与裁决，仅作为舆情线索保留并加限定语。
4. **无更高层级证据可裁决时**：如实呈现"材料内部无更高层级证据可裁决"，不做超出材料的判断。
5. 审计侧强制项：引用存在多源分歧的主题而未作分歧分析的句段，标记 `CONFLICT_UNADDRESSED`。

## 3. 审计检查项与状态

| 检查项 | 含义 | 修订动作 |
|---|---|---|
| `SOURCE_NOT_FOUND` | 来源材料名不可解析 | 修正材料名 |
| `LOCATOR_NOT_FOUND` | 具体位置不可回查 | 修正定位写法 |
| `NUMBER_MISMATCH` | 数值无法在被引位置复现 | 修正数值或更换来源 |
| `MISATTRIBUTED` | 数值出现在其他来源（张冠李戴） | 修正归属 |
| `MISSING_CITATION` | 事实句无来源标注 | 补充标注 |
| `ALLEGATION` | 传闻/指控写成确定事实 | 加限定语或改转述 |
| `CONFLICT_UNADDRESSED` | 引用分歧主题未作分析 | 补"各方数据—口径差异—判断"分析 |

主张状态：`SUPPORTED`（受支持）／`WEAK_LOCATOR`（定位弱）／`FLAGGED`（已标记）／`CONTRADICTED`（与材料矛盾）／`UNVERIFIABLE`（无法验证）。

## 4. 忠实度与容差口径

- **忠实度 = 受支持主张数 ÷ 事实性主张总数**（与赛题评分公式同构）。
- 容差：跨源数值比较 3%（处理四舍五入／单位换算）；派生值复算（比值／差值）4%；表格汇总行复算（合计／均值）1%。
- 事实性主张的判定：含来源标注的句子、含数字的句子、含专名且有"发布／成立／推出／融资／上市／评审／实测"等强事实动词的句子。
- 分析句（综上／总体来看／表明等引导且无新事实）不计入分母，但**不得夹带未经标注的数字**，夹带即升格为事实句。

## 5. 修订闭环（生成—自审—修正）

1. 生成主体产稿后，审计主体**只依据草稿与原始材料**独立逐句审计（双主体信息隔离）。
2. 按审计报告逐条修订：补来源／改数值／换来源／加限定语／补分歧分析。
3. 修订稿另存后**复审**，直至达标：**忠实度 ≥98% 为合格线，离线模式建议 100%**。
4. **未通过审计（非 SUPPORTED）的数字与结论不得进入终稿**；无法修复的主张应删除而非保留。
5. 全部程序化产物（corpus／conflicts／evidence_pack／audit）随终稿留存，保证"生成—审计—修正"全过程可追溯。
